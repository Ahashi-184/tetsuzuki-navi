# 手続きナビ

もしもの時の準備から、亡くなった後の手続きまでを、やるべき順に案内するWebアプリです。

公開URL：https://ahashi-184.github.io/tetsuzuki-navi/

## 機能
- タイトル画面から「生前の準備」「亡くなった後の手続き」「記録帳」「使い方」を選んで使います
- 生前の準備：元気なうちや、入院・介護が始まったときに家族が確認しておくことのチェックリスト
- 亡くなった後：当てはまる項目を選ぶと、必要な手続きを期限の近い順に表示（亡くなった日は後から入力できます）
- 記録帳：見つかった資産・契約を書き留め、文章や画像でLINEなどに共有
- バックアップ：入力内容をファイルに保存し、機種変更後に復元
- ホーム画面に追加して、アプリとして使用可能（電波がなくても表示）

## ご利用にあたって
- 表示される手続きや期限は一般的な目安です。正確な内容は、役所や専門家にご確認ください。
- 入力内容は利用者の端末の中だけに保存され、外部には送信されません。
