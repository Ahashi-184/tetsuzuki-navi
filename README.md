# 手続きナビ

ご家族が亡くなる前の準備から、亡くなった後の手続きまでを、やるべき順に案内するWebアプリです。

## 特徴
- 事前の準備：元気なうちや入院・余命宣告の時点で、家族が確認しておくことを案内
- 亡くなった後：亡くなった日と、当てはまる項目を入力するだけで手続きリストを作成
- 期限が近いもの・過ぎたものを色で表示
- 入力内容は利用者の端末内にのみ保存（サーバーには送信しません）

## 注意
表示される期限は一般的な目安です。個別の判断は、役所や専門家にご確認ください。
